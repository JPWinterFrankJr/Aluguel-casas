CATÁLOGO MORADA — ALUGUEL DIRETO COM O PROPRIETÁRIO

Abra index.html no navegador. Para publicar, envie index.html a uma hospedagem estática (ex.: Netlify).

COMO EDITAR
1. Abra index.html num editor de texto.
2. Encontre "const TELEFONE = '';" e insira seu número com 55 + DDD + telefone. Ex.: '5547999999999'.
3. Encontre "const imoveis = [". Cada bloco representa um imóvel. Edite tipo, nome, local, preco (apenas números), quartos, banheiros, vagas, area, descricao e fotos.
4. Em fotos, coloque links de imagens ou caminhos como 'fotos/imovel1/sala.jpg'.
5. Para fotos locais, crie a pasta fotos e coloque os arquivos nela.

Os imóveis e suas fotos atuais são ILUSTRATIVOS. Confirme todos os dados antes da publicação.
Tecnologias: HTML5, CSS, Tailwind CDN e JavaScript.
O site usa Google Fonts e Tailwind CDN, portanto precisa de conexão para carregar esses estilos; fotos remotas também precisam de conexão.
